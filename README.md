## 🚀 Proyectos Principales

### 🎓 [TABE — Tu Asistente de Bolsillo Estudiantil](https://tabe.com.ar)
> **Producto principal · Web & Android**
- Plataforma académica integral para estudiantes universitarios diseñada para centralizar el cursado, el estudio activo y la productividad.
- **Funcionalidades:** mapa interactivo de correlatividades (React Flow), asistente académico con IA (TABE AI), editor de apuntes estilo Notion (Tiptap + KaTeX), flashcards con repetición espaciada (SM-2), biblioteca PDF, salas de estudio en tiempo real (WebRTC) y gamificación (Pomodoro con bosque virtual, XP y minijuegos).
- **Stack:** `React 18` · `TypeScript` · `Vite` · `Tailwind CSS` · `TanStack Query` · `Supabase (PostgreSQL, Auth, RLS, Realtime, Edge Functions)` · `Capacitor` · `Vercel`

### 💼 [StackHard — Sistemas Web a Medida](https://stack-hard.vercel.app)
> **Desarrollo freelance & soluciones comerciales**
- Desarrollo de sistemas de gestión comercial (ventas, clientes, cobros recurrentes e inventario) y aplicaciones web para comercios y pymes.
- **Stack:** `Next.js` · `React` · `TypeScript` · `Tailwind CSS` · `Supabase` · `PostgreSQL` · `Docker` · `Vercel`
